# Design Demo 前端设计规范

> 版本：3.1 · 2026-09-10
>
> 适用范围：设计展示入口、共享控件、四个基础页面、实验室与导出示例。
>
> 本次保留原规范的十二章结构，将业务示例和旧颜色合同更新为纯设计语言。历史业务实现已从仓库移除。

## 0. 复现任务定义

### 0.1 一句话定位

Design Demo 是一套可以操作、编辑和复用的网页设计语言展示。它不承载账号、交易或行业业务。

视觉气质：**清晰、清爽、圆润、克制；每一次交互都有可预测的反馈。**

### 0.2 四个基础页面与独立实验室

- 总览：颜色、布局、形状、间距和反馈原则。
- 细节：输入、菜单、按钮、开关、分段切换、弹窗、卡片和状态；提供实际运行的代码。
- 温度：用户控制标题、署名、富文本、图片与卡片，自行决定内容结构。
- 细则：逐章呈现本文件，目录在切换正文时仍然存在。
- 实验室：独立的玻璃材质与物理反馈实验，不修改基础四页。

五个入口分别路由，不拼成一个长页面；页内跳转不能改变当前页面。

### 0.3 复现成功的判断标准

1. 四个基础色贯穿所有页面，不出现额外的语义色或深色代码面板。
2. 控件具有明确的默认、悬停、聚焦、按下、禁用、选中与异常状态。
3. 文本不被按钮裁切，输入框缺口前后都有完整边线。
4. 弹窗支持确认、取消、关闭按钮、退出键及遮罩关闭。
5. 自定义编辑与实时预览确实相通，不以提示消息代替操作。
6. 桌面和移动端都可使用，浏览器刷新与历史导航保持可预测。
7. 不能仅凭语法检查或源码正则断言“交互通过”。

### 0.4 规则优先级

用户最新明确要求优先。本文件描述当前运行合同；历史代码和旧样式只用于理解迁移背景，不是新增组件的依据。

## 1. 视觉北极星

### 1.1 设计原则

- 清晰：一眼区分内容、辅助信息与可操作元素。
- 一致：相同控件采用相同的尺寸、反馈、焦点和关闭行为。
- 克制：仅四个基础色，通过形状、透明度和文字区分状态。
- 用户控制：可取消、可修改、可导出；不替用户提交或发布。
- 有目的的动效：帮助理解状态变化，不妨碍连续操作。

### 1.2 官方依据与本项目取舍

[Google Material Design：交互状态](https://m3.material.io/foundations/interaction/states/overview)强调一致应用组件状态，并通过多个视觉线索表达状态。本项目以状态层、焦点描边、文字和图形落实这一点。

[Apple 人机界面指南：可访问性](https://developer.apple.com/design/human-interface-guidelines/accessibility)强调可感知、一致、可适应的界面，不仅依赖颜色传递信息，并支持键盘与足够大的操作目标。本项目将网页触控目标设为至少四十四像素；这是一项网页实现约定，不是把原生平台点数直接等同于像素。

[Apple 人机界面指南：动效](https://developer.apple.com/design/human-interface-guidelines/motion)强调有目的、简短、可选择的动效。本项目响应系统减少动态效果设置，不依靠动画传递唯一的重要信息。

这是借鉴原则的独立网页实现，不是官方组件库，也不宣称已通过任何官方认证。四个基础色是本项目明确的设计限制，并非官方要求。

### 1.3 品牌与语言

项目名仅为 Design Demo。界面说明和操作使用中文，代码标识符与来源名称保留原文。功能图标使用统一线性图形，不使用表情符号。

## 2. 页面骨架与空间系统

### 2.1 桌面布局

全局左侧栏保持稳定；右侧主内容独立滚动。细则页面另有常驻章节目录；温度页面在足够宽时采用编辑与预览双栏。

```css
body {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  height: 100dvh;
  overflow: hidden;
}
.main-content {
  min-width: 0;
  height: 100dvh;
  overflow: auto;
}
```

正文外层不设置会截断粘性定位的隐藏溢出。所有网格子项必须允许收缩。

### 2.2 空间

采用四像素基础网格，常用间距为四、八、十二、十六、二十四、三十二、四十八和六十四像素。

正文宽度上限一千四百四十像素；桌面内边距在二十四到六十四像素之间响应变化。组件展示区三十二像素内边距，小屏逐步减小。

### 2.3 响应式

- 一千像素以下，复杂编辑与预览改为单列。
- 七百六十七像素以下，全局导航转为顶部固定可见的四项导航。
- 移动端章节目录为有界可滚动容器，切换章节后继续可用。
- 三百二十像素宽度下不能出现页面横向溢出。
- 代码、表格允许在自己的容器内横向滚动，不撑开整页。

## 3. 设计变量约定

### 3.1 仅四个基础色

```css
:root {
  --primary: #4A90D9;
  --container: #D3E4FD;
  --surface: #F9F9FF;
  --ink: #1A1B21;
  --outline: color-mix(in srgb, var(--ink) 28%, transparent);
  --muted: color-mix(in srgb, var(--ink) 72%, var(--surface));
  --soft: color-mix(in srgb, var(--container) 32%, var(--surface));
  --hover: color-mix(in srgb, var(--ink) 7%, transparent);
}
```

交互蓝用于主按钮、选中轨道与焦点；容器蓝用于选择背景和强调容器；画布白承载内容；文字墨用于正文、轮廓和遮罩。

透明度混合不新增基础色。禁止为成功、错误、警告另开红绿橙色。错误同时使用说明文字和虚线边框。主按钮使用交互蓝与文字墨混合得到的深蓝底，搭配画布白文字；正常文字对比度至少达到四点五比一。

### 3.2 字号与字重

正文十六像素，说明十四像素，辅助十二像素。组件标题二十像素，章节标题二十四像素，页面标题三十二像素。大屏总览主视觉可使用四十像素；移动端页面标题收敛到二十八像素。

正文正常字重；标题及当前操作使用中等或半粗字重。中文字体优先系统黑体，不混入装饰字体。

### 3.3 形状与层级

输入框八像素圆角，菜单十二像素，普通卡片二十像素，展示容器二十四像素。按钮和分段切换使用胶囊形。

基础页面的普通容器只使用弱边框或填充；阴影留给弹窗、菜单和轻提示。基础页面禁止渐变、玻璃态和多重装饰阴影。实验室按用户授权单独允许玻璃材质、边缘高光和柔和投影，仍不引入额外基础色。

## 4. 图标、文字和内容语气

### 4.1 图标

导航使用同一套二十四像素线性图标。按钮图标二十像素，与文字居中对齐。纯图标操作必须有可访问名称。

### 4.2 文案

- 操作直接说明动作，例如“添加内容”“保存到本机”“导出内容”。
- 异常说明下一步，例如“存储空间不足，请导出内容保存”。
- 不引入预设行业、平台背景或身份。
- 卡片、模块导航不附加序号。规范原有章节编号是文档结构，不属于卡片编号。

### 4.3 内容层次

标题回答“是什么”，正文回答“为什么”，操作说明“能做什么”。不依靠大段标签或装饰数字制造层级。

## 5. 组件合同

### 5.1 按钮与涟漪

主操作填充蓝色；次操作描边；低优先级操作使用文字按钮。按钮至少四十八像素高；紧凑工具与模块标签至少四十四像素高。

涟漪从按下触点即时展开，键盘触发从中心展开。直径最多一百六十像素，并始终裁切在按钮边界内。重复按下替换旧涟漪，不叠加重影。涟漪不占布局、不截获事件，结束后移除。禁用按钮不触发业务或涟漪。

### 5.2 输入框

统一调用 `createMdInput()`。输入值和标签转义；占位只允许一个空格。输入框使用关联标签、字段组和图例形成缺口，不叠加遮色块伪造边框。

```js
createMdInput({
  id: 'title',
  label: '标题',
  value: '',
});
```

高度五十六像素；多行文本不可手动拖拽尺寸。默认标签在框内；聚焦或有值时浮起。浮动缺口从左侧内边距之后开始，不能消失整个左上边框。异常字段提供关联说明及无效语义。

### 5.3 下拉菜单

统一调用 `createMdSelect()`；不使用原生选择框伪装。触发器连接菜单与标签，选项表达选中状态。

方向键移动，首尾键跳转，回车或空格选择，退出键关闭并恢复焦点；点击外部与切换焦点关闭菜单。长菜单内部滚动。

### 5.4 开关与分段切换

开关使用原生复选输入及开关语义，键盘空格可操作。轨道与滑块的位置共同表达状态；禁用态保留语义。

顶部多项切换使用居中的透明文字按钮：未选中项融入画布，选中项只显示细边框和更明确的字重；切换后只刷新对应子面板，并以一次短暂渐入建立空间连续性。只有活动标签进入正常制表导航序列，左右方向键切换。取消滑动背景，只保留裁切在控件内的涟漪。富文本工具栏的可见命令使用英文 `Bold`、`Italic`、`Underline`、`List`、`Link`、`Image`，避免图标或语言混淆。

### 5.5 弹窗与底部菜单

使用原生对话框的模态行为，隔离背景焦点，支持退出键与焦点恢复。确认可校验输入；取消、关闭与遮罩点击关闭。打开和关闭均给出简短过渡，减少动态效果时立即完成。

底部菜单遵循同一关闭合同，只改变位置与入场方向。危险操作先说明后果，不增加红色。

### 5.6 轻提示与非成功状态

轻提示只用于低风险反馈，不承载唯一的关键结果；可以主动关闭。保存结果同时保留在编辑器状态说明中。

空状态包含原因与下一步；进度使用真实数值、进度条及文字，以三百毫秒过渡到新位置，连续点击可从当前显示值继续变化。错误与禁用不能仅靠颜色区别。轻提示的水平定位使用独立位移属性，入场动画不得改变水平中心。

### 5.7 卡片

卡片可为描边或填充，不附加序号。内容、间距和操作层级一致。演示卡片打开详情，绝不改变为总览路由。

### 5.8 富文本与用户控制

正文是真实可编辑区域，支持选中文字后加粗、斜体、下划线、列表与链接。图片由用户从本机选择，不自动上传。粘贴默认使用纯文本，预览移除不允许的标签与属性。

用户可编辑标题和署名、决定是否显示署名和卡片、添加及移除卡片、移动顺序、选择描边或填充。草稿写入本机存储；导出包含正文和卡片的结构化文件。重置需确认。

当前范围不包括多人协作、在线发布、后端存储或完整文档处理器的高级排版。

### 5.9 可复制模块

“结构”提供当前示例的真实标记；“样式”与“交互”来自本页实际使用的共享文件。下载示例把三者组合成可独立打开的网页，不能省略所需依赖。

### 5.10 实验室玻璃材质

- 玻璃仅用于浮动卡片、工具栏和弹窗。调节区保持实色，不堆叠多层浅色玻璃。
- 卡片默认背景模糊二十四像素、表面不透明度百分之六十八；提供轻透、柔雾、厚实三种预设及连续调节。
- 文字保持实色；边缘高光、背景模糊和轻投影共同区分层级。
- 大型弹窗使用至少百分之八十八的不透明度，保证输入任务清晰。
- 拖动保留抓取偏移、跟随指针；松手后使用临界阻尼弹簧归位。再次抓取可中断回弹，不等待动画完成。
- 方向键是拖动的替代方式；起始键和归位按钮恢复原位。拖动区域保持触控边界，不阻止页面其他区域滚动。
- 减少动态效果时关闭自动回弹和非必要位移，仍允许用户直接移动。
- 降低透明度、增强对比度或不支持背景模糊时使用实色回退。系统降低透明度时可主动进行本页玻璃预览，离开页面即清除；增强对比度不可由该预览绕过。
- 页面卸载时注销监听器、尺寸观察器、待执行帧与实验弹窗，不能影响其他页面。
- 样式复制包含当前参数、独立颜色变量和可访问性回退；它是材质样式，不冒充完整拖动组件。

## 6. 动效系统

### 6.1 时长

- 页面退出一百四十毫秒，进入二百八十毫秒。
- 常规状态一百八十到二百四十毫秒。
- 分段切换不使用位移动画；进度三百毫秒。
- 涟漪三百六十毫秒。

### 6.2 时序

先退出，再替换结构，再进入。路由更新使用版本标记，快速连续操作只保留最后一次结果。动画不得阻塞用户继续选择。

章节切换保留导航节点，仅更新正文；切换前后保持主滚动位置，若新章节高度不足则稳定地限制在该章节的最大可滚动位置，不强制跳回顶部。分段切换直接改变状态，只用有界涟漪反馈点击。

### 6.3 减少动态效果

响应 `prefers-reduced-motion: reduce`，停止位移、涟漪和样式过渡，保留选中状态、文字与焦点。不通过循环动画表达唯一的状态信息。

## 7. 页面组合配方

### 7.1 总览

页面标题与介绍 → 设计语言主视觉与可操作缩影 → 四色色板 → 层级、空间与动效原则。

总览只承担方向说明，不把全部模块塞入首页。

### 7.2 细节

模块目录 → 单独组件展示 → 真实状态 → 可展开代码 → 完整示例下载。

页内目标与页面路由分开。示例点击不造成意外的首页跳转。

### 7.3 温度

帖子、卡片、预览三种编辑视图 → 保存、导出与重置 → 实时呈现。

内容状态独立于视图节点；切换标签或暂时离开页面不丢失当前编辑。刷新恢复最后一次主动保存的草稿。

### 7.4 细则

常驻目录 → 当前章节 → 上一章与下一章。地址记录章节，刷新和历史导航恢复相应位置。

### 7.5 实验室

材质观察窗与浮动控件 → 材质调校 → 反馈与可访问性说明 → 当前材质代码。

桌面场景与调节区并排，中小屏改为纵向。背景仅通过明确操作移动，不使用持续漂移动画。实验室采用 `apple-design` 技能中的即时反馈、可打断性、空间一致性和材质层级建议；这是网页模拟，不是系统原生玻璃。

## 8. 可访问性和交互完整性

- 所有输入有标签，错误关联说明，图标按钮有名称。
- 焦点清晰可见；操作不只依赖悬停。
- 弹窗隔离背景，关闭恢复触发器焦点。
- 下拉菜单和标签页支持完整键盘路径。
- 状态至少有颜色以外的线索。
- 正文与主操作文字检查对比度；禁用态不作为正常文字对比基准。
- 浏览器缩放到百分之二百仍能访问所有功能。
- 图片可在编辑区选择删除，不向任何服务上传。
- 重要结果持续保留，不只依赖短暂提示。
- 错误不能静默吞掉或假装成功。

## 9. 推荐实现顺序

1. 先统一颜色、文字、布局与断点。
2. 复用输入、菜单、开关、弹窗和反馈模块。
3. 独立实现基础四页、实验室路由及页内目标。
4. 连接富文本、卡片状态与预览。
5. 读取规范、保持目录、处理深链接。
6. 下载真实模块，检查脱离应用后仍可操作。
7. 多轮浏览器测试与截图复核后再交付。

所有新增工作限定在展示入口；旧文件物理删除必须单独列明并确认。

## 10. 视觉验收清单

### 10.1 视觉

- [ ] 四个基础色，无额外语义色。
- [ ] 基础四页与实验室分别呈现，没有旧业务内容。
- [ ] 输入标签缺口前有边线，按钮文字与图标不裁切。
- [ ] 卡片与模块标签没有编号。
- [ ] 代码背景与页面同属浅色系统。

### 10.2 功能

- [ ] 页面切换、深链接、刷新和后退一致。
- [ ] 每个模块目标停留在细节页。
- [ ] 章节切换后目录依然存在。
- [ ] 弹窗的所有关闭方式、确认校验、焦点恢复通过。
- [ ] 下拉框、开关与标签页键盘交互通过。
- [ ] 富文本格式、链接与图片进入实际预览。
- [ ] 卡片编辑、增减、排序、样式与显示开关生效。
- [ ] 草稿可刷新恢复，导出内容准确，重置可取消。
